This is development documentation on the FYP Career Preparation Platform: KerjaReady

User:
1. Students/Candidate
2. Recruiters

Features:
1. Student can upload resume to get resume improvement tips
2. Student can select a target role, then compare the role to their resume to see how fit they are to the role
3. Student can get skill gap analysis result so they know what skills they lack for the selected job
4. Student can get a learning roadmap to fill in the gap
5. Student can browse and apply job
6. Recruiters can post and manage job applications
7. Recruiters can accept or reject the job applications. If reject, must provide reasons.
